# Personal Portfolio Website

This repository contains the source code for my personal portfolio website. It was created as part of a school project and serves as a place to showcase my profile, skills, projects, and interests in software development.

**Live Website:**
https://vienna460.github.io/

---

## About

This portfolio introduces who I am as a Software Engineering student and highlights the projects I have worked on. It also demonstrates my understanding of modern web development through a responsive and interactive website.

The website includes:

* Personal profile and biodata
* Programming skills
* Project showcase
* Future project plans
* Contact information
* Interactive user interface

## Running the Project

Clone the repository:

```bash
git clone https://github.com/Vienna460/Vienna460.github.io.git
```

Open the project directory:

```bash
cd Vienna460.github.io
```

Then open `index.html` in your web browser or run the project using a local development server such as VS Code Live Server.
